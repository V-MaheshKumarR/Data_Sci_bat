PATCH INSTRUCTIONS
==================
1. Copy ALL files/folders from this zip into your soundml_fixed/ project root,
   overwriting existing files when prompted.

2. Delete any old .joblib files:
     soundml_fixed\backend\ml\models\*.joblib  (delete all of them)

3. Double-click  train.bat  — this builds fresh models with your local sklearn.

4. After training completes, double-click  run_server.bat  to start the API.

WHY THIS PATCH:
  - Old .joblib files were saved with sklearn 1.8 and can't load on sklearn 1.4
  - registry.json has been reset (blank slate — training will repopulate it)
  - Pydantic model_ namespace warnings are now suppressed
  - Server now starts cleanly even if no model is loaded yet
  - promote_best.py automatically promotes the best trained model
